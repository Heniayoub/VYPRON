# VYPRON v2 — الحزمة الجاهزة

## الملفات
- `index.html`: واجهة المنصة.
- `style.css`: تصميم أسود وأحمر ومتجاوب.
- `app.js`: تسجيل الدخول، إنشاء الشركات، اختيار مساحة الشركة، وإدارة العملاء والوكلاء والخدمات والطلبات والاشتراكات والشركاء وسجل العمليات والدعم.
- `config.js`: إعداد Supabase العام.
- `supabase/migrations/001_vypron_multitenant.sql`: أساس multi-tenant وRLS وترحيل السجلات القديمة.
- `DEPLOYMENT_AR.md`: دليل الإعداد والنشر.

## قبل التشغيل
1. خذ نسخة احتياطية من Supabase.
2. اختبر ملف SQL على مشروع تجريبي أولاً.
3. شغّل migration في Supabase SQL Editor.
4. ضع Project URL وanon/public key في config.js فقط.
5. أنشئ حسابك، ثم أضفه إلى platform_admins بالأمر الموجود في نهاية ملف SQL.
6. ارفع محتويات المجلد إلى GitHub ثم انشره على Cloudflare Pages.

## تنبيه أمني
هذه حزمة أساس تطوير وليست اعتماداً إنتاجياً. يجب اختبار RLS على حسابين وشركتين قبل البيانات الحقيقية. واجهة الأعضاء لا تنفذ بعد دعوات مستخدمين آمنة أو ضبطاً كاملاً لكل دور. لا تضع service_role أو مفاتيح API السرية في المتصفح. لا توجد مدفوعات أو إيداعات أو سحوبات أو مراهنات حقيقية مفعّلة. أي تشغيل منظم يتطلب تراخيص السوق ومراجعة قانونية وتكاملات خادمية.
